# Umbra Nexus  Mission Control Interface

## Overview
Umbra Nexus is the interactive mission-control environment for the Umbra system.
It visualizes lead data and activity intelligence through an elegant, cinematic,
Forerunner-style interface.

## Layout
- Top Umbra crest + wordmark (small, centered).
- Center Interactive global map showing “money heat” concentrations.
- Left Panel Configurations  Loadouts (active targeting modes).
- Right Panel Live Intel Feed (new leads, verification events).
- Bottom Bar System log, clock, and API status.

## Tech Stack
- HTML5 + CSS3 + JavaScript
- Canvas-based heatmap animation
- Optional Three.js upgrade for 3-D map rotation
- Responsive layout for desktop, tablet, and mobile
