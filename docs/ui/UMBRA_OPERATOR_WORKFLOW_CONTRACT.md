\# UMBRA OPERATOR WORKFLOW CONTRACT



\# CORE PRINCIPLE



Operator workflows must remain deterministic, explainable, replay-safe, and interruption-resilient.



\---



\# OPERATOR CAPABILITIES



Operators must support:

\- replay inspection

\- convergence analysis

\- provenance tracing

\- simulation branching

\- anomaly investigation

\- ingestion validation



\---



\# WORKFLOW RULES



Operational workflows must preserve:

\- workspace state

\- replay state

\- selected entities

\- convergence context

\- simulation context



\---



\# INTERRUPTION RULES



Operational interruption must support:

\- deterministic resume

\- exact viewport restoration

\- replay continuity

\- branch continuity



\---



\# FINAL GUARANTEE



No operator workflow may lose:

\- replay context

\- provenance visibility

\- audit linkage

\- deterministic restoration
