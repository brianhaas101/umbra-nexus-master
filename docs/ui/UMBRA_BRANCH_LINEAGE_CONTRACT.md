\# UMBRA BRANCH LINEAGE CONTRACT



\# CORE PRINCIPLE



All simulation and replay branches must preserve deterministic lineage relationships.



\---



\# REQUIRED BRANCH PROPERTIES



Every branch must expose:

\- branch ID

\- parent branch

\- origin replay tick

\- mutation lineage

\- replay compatibility

\- provenance linkage



\---



\# BRANCH RULES



Branches must support:

\- deterministic replay

\- divergence analysis

\- branch comparison

\- lineage reconstruction



\---



\# FAILURE RULES



Branch failures must expose:

\- orphaned lineage

\- replay mismatch

\- divergence corruption

\- provenance gaps



Silent branch mutation is prohibited.



\---



\# FINAL GUARANTEE



No branch state may exist without:

\- lineage visibility

\- replay compatibility

\- provenance linkage
