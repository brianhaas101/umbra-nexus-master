\# UMBRA OVERLAY STACK PRIORITY CONTRACT



\# CORE PRINCIPLE



Overlay stacking must preserve operational readability and canonical truth visibility.



\---



\# REQUIRED PRIORITY ORDER



1\. Base Geography

2\. Canonical Boundaries

3\. Infrastructure

4\. Operational Entities

5\. Events

6\. Provenance Indicators

7\. Convergence Overlays

8\. Predictive Overlays

9\. Simulation Overlays

10\. Diagnostic Overlays



\---



\# VISIBILITY RULES



Canonical truth must remain visually dominant.



Simulation and predictive overlays must never obscure validated operational state.



\---



\# SYNCHRONIZATION RULES



Overlay stacks must synchronize with:

\- replay state

\- timeline state

\- convergence state

\- simulation branches



\---



\# FAILURE RULES



Overlay priority failures must expose:

\- hidden operational entities

\- replay mismatch

\- synchronization drift

\- provenance masking



Silent overlay override is prohibited.



\---



\# FINAL GUARANTEE



No overlay system may obscure:

\- canonical truth

\- provenance visibility

\- replay integrity
