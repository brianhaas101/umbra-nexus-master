\# UMBRA SECURITY AND INTEGRITY CONTRACT



\# CORE PRINCIPLE



System integrity is prioritized above rendering speed, convenience, or automation.



\---



\# INTEGRITY REQUIREMENTS



All operational systems must support:

\- provenance verification

\- replay verification

\- deterministic restoration

\- topology validation

\- audit-safe mutation history



\---



\# SECURITY REQUIREMENTS



Security systems must support:

\- role-aware access

\- immutable audit trails

\- branch isolation

\- replay protection

\- provenance protection



\---



\# PROHIBITED OPERATIONS



Prohibited:

\- silent mutation

\- provenance rewriting

\- replay alteration

\- hidden state injection

\- topology bypass



\---



\# FAILURE RULES



Security failures must expose:

\- affected systems

\- replay impact

\- provenance impact

\- synchronization impact



Silent integrity degradation is prohibited.



\---



\# FINAL GUARANTEE



No operational state may bypass:

\- provenance verification

\- replay validation

\- audit visibility

\- deterministic restoration
